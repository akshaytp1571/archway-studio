# Documentation index

Archway's documentation is organized for both developers and agents. The guides describe the implementation as it exists, not an aspirational product.

## Reading paths

- **New human contributor:** [README](../README.md) → [development](development.md) → [architecture](architecture.md) → [contributing](../CONTRIBUTING.md).
- **Coding agent:** [AGENTS.md](../AGENTS.md) → [architecture](architecture.md) → [model](model.md) → relevant source/tests.
- **Agent integrator:** [agent workflow](agent-integration.md) → [API](api.md) → [generated references](reference/README.md).
- **Operator:** [configuration](configuration.md) → [security](../SECURITY.md) → [deployment limitations](roadmap.md).
